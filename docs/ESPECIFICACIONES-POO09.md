**Escenario:** un creeper listo de Mateo amenaza a un jugador vivo de Santiago; Lucas consulta la validación del jugador y la simulación de daño y, si son aceptadas, registra una explosión de TNT en su H2.

**Cómo probar:** iniciar las tres copias como indica el README, importar `insomnia/minecraft-poo09.json`, crear los participantes y ejecutar los rechazos 05 y 06 y el éxito 07. Consultar el resultado con el pedido 08. Las instrucciones detalladas están en [GUIA-COORDINACION-POO09.md](GUIA-COORDINACION-POO09.md) y las respuestas observadas en [EVIDENCIA-POO09.md](EVIDENCIA-POO09.md).

Las dos ausencias se atribuyen a partir de listas; los servicios no envían rechazo explícito para esos casos. La regla de A3 consultada valida los datos del jugador; no se ejecutan sus reglas de explosión. El daño de Mateo es simulado y no cambia las bases ajenas. Ver el README para la configuración de URLs y los límites.
